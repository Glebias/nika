# Экспорт Wit.ai

Файл `nika_magic_tricks_export.zip` получен штатным API экспорта Wit.ai после обучения приложения. Он подтверждает четыре intent (`about_entity`, `magic_prop_query`, `magic_technique_query`, `magic_effect_query`), entity `magic_entity`, роль `rrel_entity` и размеченные utterances.

Экспорт проверен: архив открывается, содержит 7 файлов модели и не содержит Server Access Token.

Не добавлять в Git Server Access Token и другие секреты.
